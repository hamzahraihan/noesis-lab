SHA-256 of every file.

| `esp32sim.wasm`                      | The WebAssembly build of [esp32sim](https://github.com/mikroverk/esp32sim), an instruction-level ESP32 emulator: it boots the chip's own mask ROM, the second-stage bootloader and an unmodified application. This copy is built from upstream commit `964c26c` with the local patches in `../patches/`: the GPIO seam, which adds the three exports a bench needs to read what the chip drives and to drive what it reads, the I2C seam, which lets the host answer the chip's I2C controller so the bench's devices are on the bus the firmware talks on, and the SPI seam, which does the same for the chip's SPI master, with the levels of the D/C and chip-select lines the host has to know about. `scripts/build-esp32-wasm.mjs` rebuilds it; the module's bytes belong to the toolchain that built them, and the manifest records which one that was. | MIT        | Joakim Eriksson, Alice, Mattia Fiumara and the esp32sim contributors. |
