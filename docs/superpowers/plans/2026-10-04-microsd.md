# MicroSD Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a MicroSD card part with named text files through a new `sd` firmware port.

**Architecture:** New `microsd` component kind in a focused sim file; an `SdPort` on the optional-service pattern with a per-part in-memory file store owned by the engine (surviving rebuilds and reloads, pruned on removal); Wokwi artwork wired through `WOKWI_PARTS`.

**Tech Stack:** TypeScript, Vitest, existing solver (no stamps — ground topology only), `@wokwi/elements` artwork.

**Spec:** `docs/superpowers/specs/2026-10-04-microsd-design.md`

## Global Constraints

- Pin sizes in millimetres; element `pinInfo` px convert at 25.4/96.
- Text files only in v1; FAT, the SPI command protocol, and binary files are not modeled.
- Card cap is 1 MB (1,048,576 length units); writes past it write nothing and return 0.
- Files survive reloads and rebuilds; removal of the part clears its store.

## Review Focus

- `sd.read` of a missing file returns `""` instead of throwing.
- Filenames with path separators are stored verbatim (flat namespace, no directories).
- Overwriting an existing file replaces it and re-counts bytes (no double-count leak).
- Removing the card part clears its files (a fresh card reads missing).
- `sd.write` with an empty filename still stores and reads back (no silent drop).

### Task 2: `sd` firmware port and file store

**Files:**
- Modify: `src/sim/firmware/interpreter.ts` (`SdPort` + dispatch + handler)
- Modify: `src/sim/engine.ts` (per-part file store + accessors)
- Modify: `src/ui/simulation.ts` (`sd` services + lookup on `CS` net)
- Test: `src/sim/firmware/sd.test.ts` (create); extend `src/sim/sdcard.test.ts` with store tests

**Interfaces:**
- Consumes: `microsdDefinition()`, `SD_CARD_BYTES` from Task 1; member-call dispatch beside the `dialer.*` branch; `dialerOnPin` lookup shape.
- Produces: `SdPort { begin(pin): number; write(pin, name, text): number; read(pin, name): string; exists(pin, name): number; remove(pin, name): number }` (optional on `FirmwareServices`); engine `sdBegin/sdWrite/sdRead/sdExists/sdRemove(partId, ...)` accessors, with `sdBegin` returning boolean (card on bench) while the port-level `begin` normalizes to 1/0.

Engine store: `sdFiles = Map<partId, Map<name, text>>` plus `sdBytes(partId): number` (sum of `text.length`). Methods: `sdBegin(partId): boolean` (true when the part is on the bench), `sdWrite(partId, name, text): number` (0 when it would exceed the cap, else stores and returns `text.length`; overwriting replaces and recounts), `sdRead(partId, name): string` ("" missing), `sdExists`, `sdRemove` (1 removed / 0 absent). Created lazily on first write; `rebuild()` prunes only part ids no longer on the bench — never cleared on rebuild or reload. Filenames stored verbatim (flat namespace; `/` has no meaning, recorded in code).

Interpreter: `if (callee.target.name === 'sd' || callee.target.name === 'SD') return this.evaluateSdCall(...)` after the dialer branch. Handler (sync): string args extracted with the `lcd.print` guard (`typeof args[n] === 'string' ? args[n] : String(asNumber(...))`); `begin` returns `services.sd?.begin(pin) ? 1 : 0`; `write` returns `services.sd?.write(pin, name, text) ?? 0`; `read` returns `services.sd?.read(pin, name) ?? ""`; `exists`/`remove` return `services.sd ? ... : 0`; default 0.

Simulation: `sd: { begin: (pin) => this.sdOnPin(pin) ? 1 : 0, write: (pin, name, text) => { const part = this.sdOnPin(pin); return part ? this.engine.sdWrite(part.id, name, text) : 0; }, ... }` with `sdOnPin` mirroring `dialerOnPin` on the `CS` pin.

```ts
import { describe, expect, it } from 'vitest';
import { FirmwareRunner, type FirmwareServices } from './interpreter';

function stubServices(sd?: {
  begin: (pin: number) => boolean;
  write: (pin: number, name: string, text: string) => number;
  read: (pin: number, name: string) => string;
  exists: (pin: number, name: string) => number;
  remove: (pin: number, name: string) => number;
}): FirmwareServices {
  return {
    nowMs: () => 0,
    pinMode: () => {},
    digitalWrite: () => {},
    digitalRead: () => 0,
    analogWrite: () => {},
    analogRead: () => 0,
    serialBegin: () => {},
    serialWrite: () => {},
    wire: { begin: () => {}, beginTransmission: () => {}, write: () => 1, endTransmission: () => 0, requestFrom: () => 0, read: () => -1, available: () => 0 },
    spi: { begin: () => {}, transfer: () => 0, end: () => 0 },
    ...(sd ? { sd } : {}),
  };
}

describe('sd firmware', () => {
  it('round-trips a file through the port', () => {
    const store = new Map<string, string>();
    const seen: string[] = [];
    const services = stubServices({
      begin: () => true,
      write: (_pin, name, text) => { store.set(name, text); return text.length; },
      read: (_pin, name) => store.get(name) ?? '',
      exists: (_pin, name) => (store.has(name) ? 1 : 0),
      remove: (_pin, name) => (store.delete(name) ? 1 : 0),
    });
    const runner = new FirmwareRunner(
      'void setup() { sd.begin(10); sd.write(10, "log.txt", "hi"); Serial.println(sd.read(10, "log.txt")); } void loop() { delay(1000); }',
      { ...services, serialWrite: (text) => seen.push(text) },
    );
    let guard = 0;
    while (runner.step() !== null && guard++ < 100_000) {}
    expect(seen.join('')).toContain('hi');
  });

  it('fails closed with no sd service', () => {
    const seen: string[] = [];
    const runner = new FirmwareRunner(
      'void setup() { Serial.println(sd.begin(10)); Serial.println(sd.read(10, "x")); } void loop() { delay(1000); }',
      { ...stubServices(), serialWrite: (text) => seen.push(text) },
    );
    let guard = 0;
    while (runner.step() !== null && guard++ < 100_000) {}
    expect(seen.join('')).toContain('0');
  });
});
```
